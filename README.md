# Lumen 3D Art Gallery — Chromatic Drift

An interactive, immersive 3D virtual art gallery built with **Three.js**, **TypeScript**, and **Vite**.

## ✨ Features

- **3D Spatial Exploration**: Walk through the gallery hall with first-person navigation, fluid camera movement, and realistic architectural lighting.
- **Interactive Artworks**: Click or approach any painting to focus in and read detailed exhibition notes.
- **Built-in Exhibition Editor**: Add, modify, reorder, or replace artworks directly in the gallery UI.
- **Minimap & Navigation**: Built-in minimap for orientation and quick navigation.
- **Responsive Controls**: Optimized for desktop (keyboard + mouse) and mobile touch controls.

## 🚀 Getting Started

### Prerequisites

- Node.js (version 18 or newer recommended)
- npm or yarn

### Installation

```bash
git clone https://github.com/Virocchan/vs3dgallery.git
cd vs3dgallery
npm install
```

### Development

Run the local development server:

```bash
npm run dev
```

Open your browser at `http://localhost:5173`.

### Production Build

Build for production:

```bash
npm run build
```

Preview the production build locally:

```bash
npm run preview
```

## 🛠️ Tech Stack

- **Three.js** — 3D graphics and WebGL rendering
- **TypeScript** — Type safety and modern JavaScript features
- **Vite** — Fast frontend tooling and dev server
